# User guide

## Academics

Use Academics to create programmes, semesters, subjects, units and topics. Mark topics complete to update the unit-level completion percentage.

## Calendar

Switch between Month, Week, Day and Agenda. Add calendar events below the calendar. Events support subjects, locations and basic recurrence metadata.

## Timetable

Add recurring or one-off timetable sessions and availability entries. The app flags sessions that overlap or intersect explicitly unavailable periods.

## Tasks

Set title, subject, priority, status, due date and estimate. Completed tasks are excluded from open-task counts.

## Reminders

Create one-time or recurring reminders. Use Deliver now to request a native notification. Once a persisted notification ID exists, the reminder cannot be delivered a second time by the UI.

## Habits

Add habits and daily entries. Streaks count consecutive completed entries ending on or before today.

## Study sessions

Enter a title and subject, start the timer, pause if needed, then finish and save. Actual elapsed wall-clock seconds are persisted in the database.

## Analytics

Analytics use stored study sessions, tasks and habit entries only. No sample or fabricated values are inserted.

## Settings

Create or restore SQLite backups. Native notification behavior and privacy information are displayed here.
